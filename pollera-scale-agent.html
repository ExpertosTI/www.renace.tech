Pollera Scale Agent

Instalador Windows con branding Renace. Corre en la bandeja del sistema, lee la báscula LP7516 por puerto COM (RS232) y alimenta Odoo POS en 127.0.0.1:9070.

Descargar instalador Windows
RenacePolleraScaleAgentSetup.exe · Windows 10/11 x64 · Electron · v1.0.0

En la caja

  1. Instale el Setup en la Dell de caja.
  2. Deje el icono Renace en la bandeja (inicio con Windows).
  3. Configure el puerto COMx (no LPT) · baud 9600.
  4. Odoo → báscula LP7516 → Agente local → puerto 9070.
  5. POSAgent de impresora sigue en 9069 (sin cambios).
